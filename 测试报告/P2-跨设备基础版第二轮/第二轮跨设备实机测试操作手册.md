# 开物 Praxis 第二轮跨设备实机测试操作手册

适用版本：员工端 `kaiwu-praxis v0.5.0`、企业端 `kaiwu-praxis-enterprise v0.2.0`

测试目标：公司电脑中央部署企业端，公司电脑与家里电脑各运行一个员工端，验证真实跨设备纳管与配置下发。
推荐网络：Tailscale 虚拟内网。两台电脑只需分别能够访问互联网，不要求同时连接公司内网。

## 一、拓扑和端口

```text
公司电脑
├─ 企业管理端 DSH：127.0.0.1:3182（只在公司电脑本机管理）
├─ 企业中枢 API：公司电脑的 Tailscale IP:3099
└─ 本地员工端 A：127.0.0.1:3183

家里电脑
└─ 便携员工端 B：127.0.0.1:3080
        │
        └─ 主动连接 公司电脑的 Tailscale IP:3099
```

员工端无需开放入站端口。不要使用端口转发、DMZ 或 Tailscale Funnel，不要把 3099 直接暴露到公网。

2. 确认公司允许安装 Tailscale；如果公司有终端管控，先取得 IT 同意。
3. 公司电脑准备企业端和本地员工端；家里电脑准备一份便携交付包。
4. 两台电脑的系统时间应自动同步，时区保持正确。
5. 不要在聊天截图中展示模型 API Key、Tailscale 登录凭证、管理员令牌或 Tailscale auth key。
6. 家里电脑上的便携包先复制一份作为备份，不要直接在唯一副本上升级。

## 三、在两台电脑安装并登录 Tailscale

官方 Windows 安装说明：https://tailscale.com/docs/install/windows

1. 两台电脑都从 Tailscale 官方网站下载安装 Windows 客户端。
2. 两台电脑登录同一个测试 tailnet，或由管理员把两个账号加入同一个 tailnet。
3. 打开 PowerShell，找到本机 Tailscale IPv4：

```powershell
& 'C:\Program Files\Tailscale\tailscale.exe' ip -4
```

4. 分别记下：
   - `COMPANY_TS_IP`：公司电脑的 `100.x.y.z` 地址。
   - `HOME_TS_IP`：家里电脑的 `100.x.y.z` 地址。
5. 在家里电脑执行：

```powershell
& 'C:\Program Files\Tailscale\tailscale.exe' ping <COMPANY_TS_IP>
```

看到公司电脑名称以及 `pong` 即表示虚拟内网基础连通。显示 `direct` 最好；显示 `relay` 也可以完成测试，只是延迟可能更高。

### 截图点 1：组网连通

截取家里电脑 PowerShell 中 `tailscale ping` 成功的结果，命名为 `01-组网连通.png`。

截图前遮住登录邮箱等账号信息。Tailscale 的 `100.x` 地址不是公网地址，但如果报告要公开，可遮住最后两段。

解压后的便携包根目录应当能看到 `app`、`home`、`runtime` 和 `start.bat`。检查 `home\profiles\web\package.json`，应包含员工端 `v0.5.0` 和三个指定版本的配套插件，且不应包含 `kaiwu-praxis-enterprise`。

```powershell
$portableNode = Join-Path $portableRoot 'runtime\node\node.exe'
$dshBin = Join-Path $portableRoot 'app\node_modules\@deepseek-ai\dsh\lib\bin.js'

& $portableNode $dshBin plugin --profile web add 'git+https://github.com/motang1219/kaiwu-praxis.git#v0.5.0'
& $portableNode $dshBin plugin --profile web add '@nanmicoder/dsh-agent-teams@0.1.14'

```

若任一备用升级命令报错，停止操作并截图完整错误，不要反复删除 `home` 或 `profiles`。

## 五、启动公司电脑上的中央企业端

为避免混入第一轮数据，第二轮使用独立 SQLite 数据目录：

```powershell
$companyTsIp = '<COMPANY_TS_IP>'
$tokenBytes = New-Object byte[] 32
$tokenRng = [System.Security.Cryptography.RandomNumberGenerator]::Create()
$tokenRng.GetBytes($tokenBytes)
$adminToken = [Convert]::ToBase64String($tokenBytes)
$tokenRng.Dispose()

$env:DSH_HOME = 'C:\Users\86166\.dsh-github-clean-manager'
$env:KAIWU_ENTERPRISE_HUB_HOST = $companyTsIp
$env:KAIWU_ENTERPRISE_HUB_PORT = '3099'
$env:KAIWU_ENTERPRISE_ADMIN_TOKEN = $adminToken
$env:KAIWU_ENTERPRISE_NAME = '开物第二轮跨设备测试企业'
$env:KAIWU_ENTERPRISE_DATA_DIR = 'C:\Users\86166\.kaiwu-enterprise-round2'

Set-Clipboard $adminToken
node 'C:\Users\86166\.dsh\profiles\node_modules\@deepseek-ai\dsh\lib\bin.js' web --host 127.0.0.1 --port 3182 --no-open
```

注意：

- 将 `<COMPANY_TS_IP>` 替换成公司电脑的 Tailscale IPv4。
- 这段 PowerShell 会生成新的管理员令牌并放入剪贴板，不会打印令牌。
- 不要关闭这个 PowerShell 窗口，否则企业端和中枢会停止。
- 不要截图管理员令牌；粘贴完成后可复制普通文字覆盖剪贴板。

在公司电脑浏览器打开 http://127.0.0.1:3182：

1. 点击侧边栏“企业管理”。
2. 未鉴权时页面应自动进入“接入管理”。
3. 中枢地址填写 `http://<COMPANY_TS_IP>:3099`。
4. 管理员令牌粘贴刚生成的值。
5. 点击“保存并连接”。
6. 此时是全新的第二轮数据库，总览显示 0 属于正常现象。

## 六、从家里电脑验证中枢网络

先执行端口检查：

```powershell
Test-NetConnection <COMPANY_TS_IP> -Port 3099
Invoke-RestMethod "http://<COMPANY_TS_IP>:3099/api/health"
```

预期：

- `TcpTestSucceeded : True`
- 健康接口返回 `ok: true`、`version: 0.2.0` 和测试企业名称

### 如果端口检查失败

先确认公司电脑的企业端 PowerShell 没有关闭，且 `tailscale ping` 成功。多数情况下 Tailscale 可穿过现有防火墙；只有确认是 Windows 防火墙拦截后，才在公司电脑“管理员 PowerShell”添加一条范围受限的规则：

```powershell
New-NetFirewallRule `
  -DisplayName 'Kaiwu Enterprise Hub 3099 - Round2' `
  -Direction Inbound `
  -Action Allow `
  -Protocol TCP `
  -LocalAddress <COMPANY_TS_IP> `
  -LocalPort 3099 `
  -RemoteAddress <HOME_TS_IP>
```

不要关闭整个 Windows 防火墙，也不要把远端地址设成 `Any`。测试结束后可删除这条专用规则：

```powershell
Remove-NetFirewallRule -DisplayName 'Kaiwu Enterprise Hub 3099 - Round2'
```

## 十、远端离线队列测试

1. 企业端先停留在“批量配置”，确认家里电脑员工端 B 仍被勾选；本步骤中不要刷新页面。

## 十四、通过标准

以下条件全部满足才算第二轮通过：

- 两台物理电脑通过虚拟内网连接，家里电脑可访问公司电脑 3099。
- 企业端只安装企业插件，员工端只安装员工插件，三处均包含三个配套插件。
- 企业端能同时看到本地和远端两个独立终端，版本均为 0.5.0。
- 一次批量配置可同时落盘到公司电脑和家里电脑。
- 家里电脑离线时配置进入队列，恢复后只执行一次并成功回执。
- 企业中枢重启后终端、指令和审计数据不丢失，员工端无需重新注册。
- 中文 UI、接口结果和落盘 Markdown 均无乱码。
- 全程没有暴露或记录模型 API Key、管理员令牌和终端密钥。
