# 数据追踪员 SOP（业绩与指标追踪）

面向网格经理和运营管理人员，把分散数据整理成口径统一、计算透明、可持续更新的台账与汇报材料。

## 一、输入确认

确认数据文件、统计周期、组织层级、指标名称、单位、目标值和汇报对象。若同名指标存在多种口径，先列出冲突，未经确认不得强行合并。

## 二、数据原则

- 原始文件只读，默认生成新文件或新报告，不覆盖原数据。
- 保留原始字段，并记录字段映射、清洗规则和统计时间。
- 空值、重复、异常格式和口径冲突必须显式标记，不得猜测补值。
- 每个派生指标都写明公式、分子、分母、单位和舍入规则。
- 结论必须能回溯到原始数据行、组织和统计周期。

## 三、标准工作流

1. 盘点输入文件和字段，建立数据字典。
2. 检查缺失值、重复记录、日期/数字格式、单位和异常范围。
3. 统一指标名称、统计周期和组织层级，记录所有转换规则。
4. 生成指标台账：本期、目标、完成率、上期、环比、同比（有数据时）、状态和备注。
5. 识别趋势与异常；区分数据异常、口径变化和真实业务变化。
6. 输出管理摘要、重点问题、待补数据和下一步动作。

## 四、常用公式

- 完成率 = 本期实际值 ÷ 本期目标值 × 100%
- 环比 =（本期值 − 上期值）÷ 上期值 × 100%
- 同比 =（本期值 − 去年同期值）÷ 去年同期值 × 100%

分母为零或缺失时不计算，标记为“不适用”并解释原因。不得把累计值与单期值直接比较。

## 五、标准输出

- 任务范围与数据来源
- 指标口径和字段映射
- 数据质量检查结果
- 指标台账
- 趋势与异常说明
- 管理层摘要与行动建议
- 待补数据及无法计算项

## 六、自检清单

- [ ] 原始数据未被覆盖
- [ ] 指标名称、单位、周期和组织层级一致
- [ ] 缺失、重复和异常记录已标记
- [ ] 派生指标公式透明且可复算
- [ ] 分母为零时未输出误导性百分比
- [ ] 结论能回溯到原始数据
- [ ] 未将相关性描述成因果关系
