## 5. 接手人第一天 Checklist

1. 克隆两个仓库，确认不是把两个插件合并安装。
2. 确认两个仓库的 `main`、版本标签和远程地址一致；不要用员工端覆盖企业端或反向覆盖。
3. 运行两个仓库的语法、接口和打包回归。
4. 从 `v0.5.1` 和 `v0.2.1` 标签各做一次空白 profile 安装，作为仓库迁移前的最终复核。
5. 核对本机便携包哈希；源码标签不等同于 GitHub 已托管 ZIP/EXE 安装包。
6. 确认本交接目录、第二轮、第三轮和 `0.5.1` 回归材料均已纳入 Git。
7. 把两个 GitHub 仓库转到公司组织或指定同事账号，并更新远程地址。
8. 轮换测试期间使用过的管理员令牌和注册码；不移交个人账号密码、API Key 或终端密钥。
